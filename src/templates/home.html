JSON API

EndpointWhat it returns
GET/apiIndex of every endpoint
GET/api/stationsStations for a mode; ?search=, ?mode=
GET/api/stopsStops of any location type; ?location_type=0-4
GET/api/rail-networkTrain and metro stations with their lines, plus line geometry
POST/api/stop-statsDaily trip counts and service span per station
POST/api/trip-statsDirect-service headways and travel times between two stations; "period": "am_peak" etc.
POST/api/tripsJourney planner with transfers
POST/api/isochroneWalking/cycling isochrone polygon for a point
GET/api/network?lat=&lon=Walkable street network around a point (GeoJSON)
POST endpoints take a JSON body; each one's request and response schema is in its docstring in src/api/.
